# 🛻 BroncoDeals

An aggregator of **overlanding & accessory deals for the 2021–2026 Ford Bronco** (6th generation).
Browse gear from Amazon, AliExpress, Temu, brand stores and social communities in one place, and
filter it down to exactly what fits your build.

![Deals](https://img.shields.io/badge/deals-60%2B-f26a1b) ![No build step](https://img.shields.io/badge/build-none-2f6fed) ![Ships to Israel](https://img.shields.io/badge/ships%20to-Israel%20%F0%9F%87%AE%F0%9F%87%B1-17a34a)

## Features

- **Rich filtering** — narrow deals by:
  - **Model year** (2021 → 2026) — only shows items compatible with the selected year
  - **Category / type** — roof racks, rooftop tents, awnings, MOLLE, lighting, recovery gear,
    fridges & power, air compressors, armor, interior, cargo, fuel & water, steps, social deals
  - **Source / website** — Amazon, AliExpress, Temu, direct brand stores, social communities
  - **Max price** — slider
  - **Ships to Israel 🇮🇱** — toggle to only show items that deliver to Israel
  - **On-sale only** — toggle to only show discounted items
  - **Full-text search** across titles, brands, tags and descriptions
- **Bilingual 🇬🇧 / 🇮🇱** — one-click switch between **English and Hebrew**, with full
  right-to-left (RTL) layout, translated UI, categories and product descriptions. The choice is
  remembered via `localStorage`. (Brand and product names stay in English.)
- **Sorting** — biggest discount, price (low/high), top rated, name
- **Live stats** — total deals, average discount, source count, ships-to-Israel count
- **Removable active-filter pills** so you always see what's applied
- **Light / dark theme** (remembered via `localStorage`), rugged desert-inspired UI
- **Zero dependencies, no build step** — pure HTML/CSS/JS, works offline and on GitHub Pages
- **Fully responsive** — sidebar collapses to the top on mobile

## Run locally

Just open `index.html` in a browser — there is no build step and no server required:

```bash
# macOS
open index.html
# Linux
xdg-open index.html
```

Or serve it (optional):

```bash
python3 -m http.server 8000   # then visit http://localhost:8000
```

## Deploy (GitHub Pages)

A workflow at `.github/workflows/deploy.yml` publishes the site to GitHub Pages on every push to the
default branch. To enable it: **Settings → Pages → Build and deployment → Source: GitHub Actions**.

## Adding or updating deals

All deals live in [`assets/data.js`](assets/data.js) as objects in the `BRONCO_DEALS` array. The UI
derives every filter (years, categories, sources, price range) automatically, so you only need to add
objects — no other code changes. Each deal looks like:

```js
{
  id: "rack-trailrax",
  title: "TrailRax Modular Roof Rack (4-Door)",
  brand: "TrailRax",
  category: "Roof Racks",           // becomes a category filter chip
  price: 899,
  originalPrice: 999,               // optional — enables the discount badge
  years: [2021, 2022, 2023, 2024, 2025, 2026],
  doors: "4-Door",                  // "2-Door" | "4-Door" | "Both"
  source: "Direct",                 // "Amazon" | "AliExpress" | "Temu" | "Direct" | "Social"
  retailer: "TrailRax",
  url: "https://trailrax.com/...",
  shipsToIsrael: false,
  rating: 4.8,
  tags: ["roof", "rack", "overland"],
  description: "Modular hardtop roof rack, 850 lb static load."
}
```

### About the data

The dataset is grounded in real products and brands that exist in the Bronco aftermarket (TrailRax,
Front Runner, ARB, Smittybilt, Rough Country, Baja Designs, Dometic, MAXTRAX, Hooke Road, IAG,
RotopaX, and more). Because marketplace listings and prices change constantly, links to Amazon,
AliExpress and Temu open **live search results** for the product so you always land on current
listings and pricing; direct-brand links point to the specific product page where known.

Prices shown are indicative snapshots — **always confirm the current price and shipping on the
retailer's site before buying.**

### Automating the feed (future)

The clean `BRONCO_DEALS` schema is designed so the dataset can later be generated by a scraper /
affiliate-API job (Amazon Product Advertising API, AliExpress open platform, etc.) writing the same
shape into `assets/data.js`. Nothing in the UI needs to change.
